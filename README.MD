# MedChange-VLM

**Grounded Vision-Language Framework for Longitudinal Chest X-Ray Analysis**

MedChange-VLM is a biomedical multimodal AI research project for analyzing changes between prior and current chest radiographs.

The project will combine vision-language modeling, temporal reasoning, lesion grounding, uncertainty estimation, and visual faithfulness auditing.

## Planned capabilities

- Chest X-ray visual question answering
- Longitudinal prior/current study comparison
- Temporal abnormality classification
- Lesion localization
- Structured radiology-style output
- Model confidence and calibration
- Visual hallucination auditing
- Agent-based verification
- FastAPI inference
- Interactive Streamlit dashboard

## Temporal labels

The project uses the following normalized temporal states:

- New
- Worsened
- Stable
- Improved
- Resolved
- Uncertain
